# Security Policy

Agradecemos reportes de segurança para este projeto.

## Versões suportadas

Como regra geral, apenas a branch `main` (versão mais recente) recebe correções de segurança.

## Como reportar uma vulnerabilidade

Não abra issue pública com detalhes sensíveis.

Use um destes caminhos:

1. Preferencial: GitHub Security Advisory (reporte privado):
   https://github.com/Flownex/firebase-backend/security/advisories/new
2. Se o fluxo acima não estiver disponível, abra uma issue pedindo contato de segurança sem expor detalhes técnicos da vulnerabilidade.

## O que incluir no reporte

- Tipo da vulnerabilidade e impacto potencial.
- Passos para reprodução.
- Versão afetada.
- Prova de conceito mínima (quando possível).
- Sugestão de correção (opcional).

## Processo de resposta

- Confirmação de recebimento: até 5 dias úteis.
- Triagem inicial: até 10 dias úteis.
- Correção e divulgação coordenada: conforme severidade e complexidade.

Nos comprometemos a tratar reportes de boa-fé com prioridade e transparência.
